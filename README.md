## Tentang Saya

Saya **Evan Purnamalila Kosasih**, Junior Developer dari **Jawa Barat, Indonesia**, yang sedang mempelajari dan mengembangkan kemampuan di bidang web dan aplikasi.

Saya senang mengeksplorasi ide, memahami cara kerja suatu sistem, dan mencoba mengubah gagasan menjadi solusi digital yang bermanfaat. Dalam proses pengembangan, saya berusaha mengutamakan logika, fungsionalitas, efisiensi, dan kebutuhan pengguna.

Saat ini, saya masih dalam tahap belajar dan terus memperdalam pemahaman melalui eksperimen serta pengerjaan proyek pribadi. Saya melihat setiap proses pengembangan sebagai kesempatan untuk memahami teknologi lebih jauh, melatih kemampuan memecahkan masalah, dan meningkatkan kualitas hasil pengembangan.

Saya terbuka terhadap ide baru, proses belajar bersama, dan kesempatan berkolaborasi untuk terus berkembang sebagai developer.

> **Prinsip saya:** *Terus belajar apa yang bisa. Kejar selagi bisa.*
